# Chordism

A chord-based polyphonic synthesizer for Schwung. Inspired by the Doboz DVNA — one note in, four voices out, with morphing level/pan and a stereo filter chain.

Loads as a `sound_generator` in Schwung's Signal Chain.

Not affiliated with or endorsed by Doboz.

## Status

Pre-alpha. Milestone 1: skeleton + silent plugin.
